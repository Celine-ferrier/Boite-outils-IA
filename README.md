# Boîte à outils IA — IMT Mines Alès

Site de ressources sur les outils d'IA pour les enseignants, construit avec MkDocs Material et publié automatiquement sur GitHub Pages.

## Modifier le site

- Les pages sont dans le dossier `docs/`, au format Markdown.
- Pour ajouter une fiche, copiez `MODELE_FICHE.md` dans le bon dossier de `docs/`, puis ajoutez-la dans la rubrique `nav` du fichier `mkdocs.yml`.
- Chaque modification enregistrée sur la branche `main` republie le site en une à deux minutes (onglet **Actions**).
