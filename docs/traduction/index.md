# Traduction français ↔ anglais

Pour proposer vos supports aux étudiants internationaux ou enseigner en anglais. La meilleure méthode combine souvent deux outils : une traduction automatique du fichier, puis une relecture du vocabulaire technique avec un assistant IA.

| Outil | Usage principal | Hébergement |
|---|---|---|
| [DeepL](deepl.md) | Traduire un fichier PowerPoint entier | <span class="badge badge-ue">Entreprise UE</span> |
| [Traduire avec un assistant IA](assistant-ia.md) | Traduire et adapter le vocabulaire technique | Selon l'assistant |
| [Sous-titres en direct PowerPoint](sous-titres-powerpoint.md) | Sous-titrer en anglais pendant une présentation | <span class="badge badge-hors-ue">Hors UE</span> |
