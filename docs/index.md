# Boîte à outils IA pour les enseignants

Des outils d'intelligence artificielle **utilisables gratuitement**, choisis pour l'enseignement supérieur, avec un tutoriel pour chacun. Partez de ce que vous voulez faire : chaque rubrique vous oriente vers l'outil adapté.

<div class="grid cards" markdown>

-   :material-chat-processing-outline:{ .lg } **Échanger avec un assistant IA**

    ---

    Préparer un cours, reformuler une consigne, générer des exercices, obtenir un avis sur un sujet d'examen.

    [Voir les assistants](assistants/index.md)

-   :material-presentation:{ .lg } **Créer des supports**

    ---

    Diaporamas, schémas, visuels, quiz interactifs, capsules vidéo.

    [Voir les outils de création](creation/index.md)

-   :material-book-search-outline:{ .lg } **Faire une recherche documentaire**

    ---

    Trouver des articles scientifiques, cartographier une littérature, interroger ses propres documents.

    [Voir les outils de recherche](recherche/index.md)

-   :material-translate:{ .lg } **Traduire un support en anglais**

    ---

    Traduire un diaporama, vérifier le vocabulaire technique, sous-titrer un cours en direct.

    [Voir les outils de traduction](traduction/index.md)

</div>

## Lire les repères sur les fiches

Chaque fiche indique où vont vos données. Ce repère vous aide à choisir l'outil selon ce que vous y déposez.

| Repère | Signification | Ce que vous pouvez y mettre |
|---|---|---|
| <span class="badge badge-souverain">Souverain ESR</span> | Hébergé par l'enseignement supérieur et la recherche | Documents de travail internes |
| <span class="badge badge-ue">Entreprise UE</span> | Entreprise européenne, soumise au RGPD | Supports de cours publiables |
| <span class="badge badge-hors-ue">Hors UE</span> | Données hébergées hors de l'Union européenne | Contenus déjà publics, sans données personnelles |

!!! warning "Règle d'or"
    Ne déposez jamais de données personnelles d'étudiants (noms, notes, copies nominatives) dans un outil d'IA, quel qu'il soit. Consultez la page [Bonnes pratiques](bonnes-pratiques.md).
