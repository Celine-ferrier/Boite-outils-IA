# NotebookLM

NotebookLM est un assistant de Google qui travaille **uniquement à partir des documents que vous lui fournissez**. Il répond à vos questions en citant le passage exact de vos sources, ce qui limite fortement les réponses inventées.

[Ouvrir NotebookLM](https://notebooklm.google.com){ .md-button .md-button--primary }

## À quoi ça sert en pédagogie

- Préparer un cours à partir de vos articles, polycopiés, normes ou rapports.
- Générer un guide de révision, une FAQ, des fiches mémo ou un quiz à partir d'un chapitre.
- Produire un **résumé audio** façon podcast, en français, pour une révision ou une introduction de séance.
- Construire une carte mentale d'un corpus pour structurer un nouveau module.

## Version gratuite

Un compte Google suffit. La version gratuite limite le nombre de carnets, de sources par carnet et de générations quotidiennes (résumés audio, questions), mais ces limites sont largement suffisantes pour un usage d'enseignant. Les documents acceptés comprennent les PDF, les documents et présentations Google, les pages web, les vidéos YouTube, les fichiers audio et le texte copié-collé.

## Cas d'usage

=== "Préparer un cours"

    Déposez 3 à 5 articles de référence sur le thème du cours, puis demandez :

    ```
    À partir de ces sources, propose un plan de séance de 2 heures
    pour des élèves ingénieurs de 2e année. Pour chaque partie,
    indique les notions clés, la source qui les traite et une
    question pour vérifier la compréhension.
    ```

=== "Créer un quiz"

    Déposez votre polycopié de chapitre, puis demandez :

    ```
    Rédige 10 questions à choix multiples sur ce chapitre, avec
    4 propositions dont une seule correcte. Pour chaque question,
    donne la bonne réponse et une explication d'une phrase.
    Varie les niveaux : rappel, compréhension, application.
    ```

    Vous pouvez ensuite importer ces questions dans Moodle ou Wooclap.

=== "Résumé audio"

    Dans le panneau **Studio**, choisissez **Résumé audio**, puis personnalisez la consigne :

    ```
    Présente ce chapitre à des étudiants de 1re année qui le
    découvrent. Insiste sur les applications industrielles et
    les erreurs fréquentes.
    ```

## Pas à pas

1. Rendez-vous sur [notebooklm.google.com](https://notebooklm.google.com) et connectez-vous avec un compte Google.

    !!! note "Capture à ajouter : page d'accueil de NotebookLM"

2. Cliquez sur **Créer un notebook**.

3. Ajoutez vos sources : glissez vos fichiers, collez un lien ou du texte. Chaque source apparaît dans le panneau de gauche.

    !!! note "Capture à ajouter : panneau des sources"

4. Posez vos questions dans la zone de discussion au centre. Les chiffres dans les réponses renvoient au passage cité : cliquez dessus pour vérifier.

5. Utilisez le panneau **Studio** à droite pour générer un résumé audio, un guide d'étude, une carte mentale ou un quiz.

    !!! note "Capture à ajouter : panneau Studio"

6. Enregistrez une réponse utile avec **Enregistrer dans une note** pour la retrouver plus tard.

## Points de vigilance

!!! warning "Données"
    Les documents sont hébergés par Google. Ne déposez ni données personnelles d'étudiants, ni documents confidentiels ou soumis à une clause de confidentialité (contrats de recherche, brevets en cours).

!!! tip "Fiabilité"
    NotebookLM s'appuie sur vos sources, mais il peut mal interpréter un passage. Vérifiez les citations avant de réutiliser un contenu, surtout pour un sujet d'examen.

!!! info "Droits d'auteur"
    Déposer un article pour votre usage personnel est acceptable, mais partager un carnet contenant des documents protégés avec vos étudiants peut poser problème. Privilégiez vos propres supports ou des documents en accès ouvert (HAL, arXiv).
