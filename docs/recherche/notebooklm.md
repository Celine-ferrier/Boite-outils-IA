# NotebookLM

<span class="badge badge-hors-ue">Hors UE</span> <span class="badge badge-gratuit">Gratuit avec un compte Google</span>

<p class="maj">Dernière vérification : septembre 2026</p>

NotebookLM est un assistant de Google qui travaille **uniquement à partir des documents que vous lui fournissez**. Il répond à vos questions en citant le passage exact de vos sources, ce qui limite fortement les réponses inventées. C'est l'outil idéal pour exploiter un corpus : articles scientifiques, rapports, polycopiés, transcriptions de cours.

[Ouvrir NotebookLM](https://notebooklm.google.com){ .md-button .md-button--primary }

## À quoi ça sert dans le supérieur

- **Synthétiser un corpus documentaire** : dégager les idées clés, les convergences et les controverses d'un ensemble d'articles.
- **Préparer un cours** à partir de vos polycopiés, rapports et publications.
- **Produire des supports de révision** : fiches de synthèse, flashcards, quiz, glossaire.
- **Varier les formats** : résumé audio façon podcast, résumé vidéo, carte mentale, infographie, diaporama.
- **Encadrer un projet** : partager un carnet de ressources avec une équipe d'étudiants ou des collègues.

## Version gratuite

Un compte Google suffit. La version gratuite permet de créer jusqu'à **100 carnets**, chacun contenant jusqu'à **50 sources** (500 000 mots et 200 Mo maximum par source), ce qui couvre largement plusieurs cours. Le nombre de générations quotidiennes (résumés audio, vidéos, questions) est limité.

**Sources acceptées** : PDF, documents et présentations Google, fichiers Word, pages web, vidéos YouTube, fichiers audio et texte copié-collé.

## Cas d'usage

=== "Synthétiser un corpus"

    **Exemple** : vous rassemblez 15 articles sur les matériaux biosourcés dans la construction pour préparer un nouveau module de génie civil.

    Dans la discussion, demandez d'abord une vue d'ensemble :

    ```
    À partir des sources de ce carnet, rédige une synthèse structurée
    en 4 parties : état des connaissances, points de consensus,
    points de controverse, questions encore ouvertes. Cite la source
    de chaque affirmation.
    ```

    Puis faites comparer les documents entre eux :

    ```
    Présente dans un tableau les principaux résultats de chaque
    article : matériau étudié, méthode, résultats clés, limites
    signalées par les auteurs.
    ```

    Dans le panneau **Studio**, le **Tableau de données** produit ce type de comparaison exportable vers Google Sheets, et le **Rapport** (document de synthèse) propose une note complète à retravailler.

=== "Préparer un cours"

    **Exemple** : un cours de mécanique des sols pour des élèves ingénieurs de 2e année, à partir de votre polycopié et de deux rapports techniques.

    ```
    À partir des sources de ce carnet, propose un plan de séance
    de 2 heures pour des élèves ingénieurs de 2e année. Pour chaque
    partie, indique les notions clés, la source qui les traite,
    une application industrielle et une question pour vérifier
    la compréhension.
    ```

    Complétez avec une **carte mentale** (panneau Studio) pour visualiser l'articulation des notions avant de construire vos diapositives.

=== "Réviser et évaluer"

    **Exemple** : des supports de révision pour un cours d'algorithmique, construits sur la taxonomie de Bloom et la récupération active (s'interroger plutôt que relire).

    ```
    À partir de ce chapitre, rédige 10 questions à choix multiples
    réparties sur les niveaux de Bloom : 3 de mémorisation,
    3 de compréhension, 4 d'application sur un cas concret.
    Pour chaque question, donne la bonne réponse, une explication
    et l'erreur fréquente que révèle chaque mauvaise réponse.
    ```

    Le panneau **Studio** génère aussi des **Fiches** (flashcards) et un **Quiz** interactif. Vous pouvez importer les questions retenues dans Moodle ou Wooclap.

=== "Audio et vidéo"

    **Exemple** : une introduction de 10 minutes à un module sur le risque industriel, à écouter avant la première séance.

    Dans le panneau **Studio**, cliquez sur l'icône crayon de **Résumé audio** pour personnaliser la consigne :

    ```
    Présente ces documents à des élèves ingénieurs qui découvrent
    le sujet. Commence par un accident industriel réel cité dans
    les sources, puis explique les notions de danger, de risque
    et de barrière de sécurité. Termine par trois questions
    à se poser avant le cours.
    ```

    Le **Résumé vidéo** fonctionne de la même manière et ajoute des visuels générés à partir de vos sources.

=== "Encadrer un projet"

    **Exemple** : un projet d'équipe en génie de l'environnement, avec une bibliographie de départ commune.

    Créez un carnet avec les ressources de départ, puis partagez-le avec les étudiants en **lecture seule** (bouton **Partager**). Ils peuvent interroger le corpus sans le modifier. Donnez-leur une consigne d'usage, par exemple :

    ```
    Quelles méthodes de mesure de la qualité de l'eau sont décrites
    dans ces sources ? Pour chacune, indique ses avantages,
    ses limites et la source correspondante.
    ```

    Rappelez-leur que la création d'un compte Google relève de leur choix : prévoyez une alternative pour les étudiants qui ne souhaitent pas en créer.

## Pas à pas

1. Rendez-vous sur [notebooklm.google.com](https://notebooklm.google.com) et connectez-vous avec un compte Google. La page d'accueil affiche vos carnets existants.

    ![Page d'accueil de NotebookLM](images/notebooklm-01-accueil.png)

2. Cliquez sur **Créer un notebook**. Une fenêtre s'ouvre pour ajouter vos premières sources : glissez vos fichiers, collez un lien web ou YouTube, ou copiez du texte.

    ![Fenêtre d'ajout de sources](images/notebooklm-02-sources.png)

3. Découvrez l'interface en trois panneaux : vos **sources** à gauche, la **discussion** au centre, le **Studio** à droite. Décochez une source pour l'exclure temporairement des réponses.

    ![Interface en trois panneaux](images/notebooklm-03-interface.png)

4. Posez vos questions dans la zone de discussion. Les numéros dans les réponses renvoient au passage cité : **cliquez dessus pour vérifier** la source.

    ![Réponse avec citations](images/notebooklm-04-citations.png)

5. Dans le panneau **Studio**, choisissez ce que vous voulez générer : résumé audio ou vidéo, carte mentale, rapport, fiches, quiz, infographie, présentation ou tableau de données.

    ![Panneau Studio](images/notebooklm-05-studio.png)

6. Pour adapter une génération à votre public, cliquez sur l'**icône crayon** à côté de l'outil et décrivez ce que vous attendez (niveau, durée, angle).

    ![Personnalisation d'une génération](images/notebooklm-06-personnaliser.png)

7. Enregistrez une réponse utile avec **Enregistrer dans une note**, puis partagez le carnet si besoin avec le bouton **Partager** en haut à droite.

    ![Partage d'un carnet](images/notebooklm-07-partage.png)

## Points de vigilance

!!! warning "Données"
    Les documents sont hébergés par Google. Ne déposez ni données personnelles d'étudiants, ni documents confidentiels : contrats de recherche, données de partenaires industriels, brevets en cours, sujets d'examen.

!!! tip "Fiabilité"
    NotebookLM s'appuie sur vos sources, mais il peut mal interpréter un passage, un tableau ou une formule. Vérifiez les citations avant de réutiliser un contenu, en particulier pour un sujet d'examen ou une synthèse bibliographique.

!!! info "Droits d'auteur"
    Déposer un article pour votre usage personnel est acceptable. En revanche, partager un carnet contenant des documents protégés (ouvrages, normes, articles sous abonnement) avec des étudiants peut poser problème. Privilégiez vos propres supports et les documents en accès ouvert (HAL, arXiv, rapports publics).

!!! note "Ne pas déléguer l'analyse"
    Une synthèse générée est un point de départ, pas une lecture du corpus. Pour un travail de recherche, lisez les sources clés et vérifiez que la synthèse ne gomme pas les nuances ou les désaccords entre auteurs.
